# Prueba Técnica - Biblioteca

Proyecto de prueba técnica para VISTA TI.

## Descripción

Aplicación web para buscar libros desde una API pública y permitir guardar favoritos en una base de datos SQL Server.

## Estructura del proyecto

- /backend : API en .NET
- /frontend : Frontend en Angular
- /database : Scripts SQL para crear la base de datos

## Base de datos

En la carpeta `/database` se incluye el script:

- create_db.sql

Este script crea la base de datos `BibliotecaDb` con las tablas necesarias (`Users` y `Favorites`).

## Estado del proyecto

- Estructura base creada
- Script de base de datos listo y funcional
